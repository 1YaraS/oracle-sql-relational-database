# Student Registration & Orders Relational Database (Oracle SQL)

## Overview
A progressive relational database project developed through structured academic lab coursework using Oracle SQL. The repository models and implements a complete schema for managing student course registrations, academic records, and transactional orders.

—

## Repository Structure & Modules

1. `01_create_tables_and_constraints.sql`: Schema definition, entity relationships, primary/foreign key constraints, and cascading rules.
2. `02_insert_sample_data.sql`: Test datasets covering students, courses, semesters, and course registrations.
3. `03_data_manipulation_update_delete.sql`: Data manipulation language (DML) operations including conditional updates and referential deletes.
4. `04_basic_queries_and_filtering.sql`: Data retrieval, arithmetic calculated columns, and WHERE filters.
5. `05_pattern_matching_and_sorting.sql`: Pattern matching (`LIKE`), numeric ranges (`BETWEEN`), and sorting (`ORDER BY`).
6. `06_top_n_queries_and_rownum.sql`: Top-N query extraction and inline views using ROWNUM.
7. `07_aggregate_functions_and_grouping.sql`: Grouping logic (`GROUP BY`), aggregation (`COUNT`, AVG, `SUM`), and post-filter conditions (`HAVING`).
8. `08_multi_table_joins.sql`: Multi-table relationships implementing INNER JOIN, LEFT JOIN, and RIGHT JOIN.
9. `09_nested_subqueries.sql`: Deep multi-level nested queries and subqueries integrated within DML operations.
10. `10_views_and_data_integrity.sql`: Complex multi-table views, string functions (`UPPER`, LOWER, ||`), CTAS backup tables, and `WITH CHECK OPTION integrity.

—

## Technical Skills Highlighted
* Database Engine: Oracle SQL / PL-SQL
* Integrity Enforcement: Primary Keys, Foreign Keys, CHECK constraints, WITH CHECK OPTION
* Query Design: Multi-table Joins, Correlated/Uncorrelated Subqueries, Inline Views
* Data Processing: Grouping, Aggregations, String Functions, and Table Backups (CTAS)
